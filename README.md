## 开发环境

Unity 6.3 LTS (6000.3.27f1) <DX12>

## 运行环境

Windows Intel-64 bit

## 可运行文件入口

Q1 - Active Ragdoll
- Build/Q1-RagdollDemo.zip

Q2 - Physics Climbing
- Build/Q1-RagdollDemo.zip

## 运行方式

1. 解压对应zip文件
2. 双击RagdollDemo/Ragdoll.exe或 Q2-PEAK_CharacterPrototype/PEAK_CharacterPrototype.exe打开
4. 在游戏主菜单点击 Start，开始测试。
5. 按 Esc 暂停或恢复游戏。

## 操作方式

WASD - 移动
E - 物品交互
Esc - 游戏菜单
Space - 跳跃 （仅限Q2）
Shift - 冲刺（仅限Q2）
LMB - 攀爬（仅限Q2）
