## 1. 需求背景与设计目标

### 1.1 体验定位

单人第三人称越肩、物理胶囊角色的攀爬玩法原型。玩家从山脚通过平地、可行走缓坡、必须抓附的陡坡与岩壁，在小型山峰路线中完成上翻、内外转角、坠落与物品交互。强调**输入可预期、物理反馈可信、失败原因可理解、镜头不晕**。

### 1.2 玩家体验目标

| 目标 | 玩家应感知到 | 禁止出现 |
|---|---|---|
| 可控性 | 左右输入符合直觉，攀爬不因相机转角失控 | A/D 反向、持续按键卡住或绕圈 |
| 抓附可信 | 距墙足够近且表面可抓才能成功 | 远处吸附、悬挂不扣体力、未抓附却耗体力 |
| 连续性 | 内外角从两侧进入均能横移过去 | 人工只标定某一侧才能过角 |
| 物理真实性 | 角色按重力下落并与物体碰撞 | 松 LMB 不掉落、瞬移穿墙 |
| 反馈及时 | 抓住、松手、落地声画动作一致 | 落地后才听到松手音效 |
| 舒适性 | 越肩跟随平滑，微小手抖不过度转镜头 | 镜头闪卡、持续抖动、异常高角度俯视 |

### 1.3 玩法闭环与范围

**核心闭环：** 观察可攀地形 → 接近岩壁 → 按住 LMB 抓附 → 消耗体力沿墙移动 → 过转角 / 上翻 → 恢复体力 / 选择下一段路线 → 抵达山顶；失败时松手或耗尽体力 → 坠落 → 落地反馈 → 重新尝试。

**包含：** 胶囊物理移动、相机、抓附/上翻/转角、体力与 HUD、拾放物品、现有两件道具、山峰测试场景、声音和视觉表现、启动暂停菜单。

**不包含：** 新增玩法、第三件道具、联网、自动存档、完整动画骨骼、商业化、任意曲面 Mesh 的通用自动攀爬、Active Ragdoll 另一题。

## 3. 角色运动系统（3C）

### 3.1 角色组件与职责

- `PhysicsPlayer`：Dynamic Rigidbody + CapsuleCollider，负责受力、重力、碰撞；禁止通过直接修改动态刚体 Transform 达成正常移动。
- `CharacterVisualRoot`：仅视觉朝向，不改根胶囊朝向。
- `ClimberPresentationPivot`：跑步前倾、轻微侧倾、落地压缩回弹；姿态每帧从**初始基准姿态**计算，禁止叠乘旧旋转。
- `HeadLookPivot`：视觉头部/朝向提示，与镜头独立；胶囊 prototype 不要求真的头骨骼。
- Camera Rig：独立记录逻辑航向、相机偏航/俯仰与遮挡状态，不能读写物理胶囊的倾斜角度形成反馈环。

### 3.2 地面移动与空中运动

**触发：** 接地，WASD 非零。**执行：** 镜头相对水平意图 → 加速度逼近目标速度；Shift 且体力可用时使用跑步目标速度；无输入时减速。**结束：** 松键/离地/进入抓附状态。**异常：** 碰墙时不能通过强制转身把摄像机拉到极限；保留有效速度/碰撞反馈。

地面移动、跑步和高处下落均遵循 Rigidbody 重力与 Collider。角色朝向与镜头平滑过渡而非互相逐帧纠正，后退时不要强制镜头突然翻转。

### 3.3 坡度分类

定义地表坡度角 `slopeAngle` 相对于水平面；`walkableSlopeMax = 48°`【建议配置】。25° 缓坡应步行通过；65°/70° 陡坡需有效 `ClimbSurface` + 抓附；不可抓悬石即使有 Collider 也不允许抓。阈值附近须避免在 Ground/Climb 间频繁抖动，可使用很小的迟滞与接地连续采样（只作为稳定判定，不新增玩法）。

## 4. 攀爬系统详细规则

### 4.1 状态机与退出条件

| 当前状态 | 触发条件 | 目标状态 | 必须执行的动作 |
|---|---|---|---|
| Ground/Air | LMB 按住；有效表面；抓附间隙合格；体力解锁 | Climb | 记录墙面与法线；音效；开始消耗体力 |
| Climb | LMB 松开 | Air | 当帧取消抓附支撑；不等待 WASD 松开；发送松手事件 |
| Climb/Corner | 体力到 0 | Air | 强制失去抓附、标记疲劳；防止自动重抓 |
| Climb | 持续 A/D 接近可转接边缘并找到有效邻面 | Corner | 验证全程胶囊空间；衔接转角轨迹 |
| Corner | 过渡结束，邻面有效 | Climb | 切换有效面和局部坐标；持续原方向键 |
| Climb | 接近顶部，按 Space 且平台/空间合法 | Mantle | 进入抬升—越边—落地路线 |
| Mantle | 到达可站立顶面 | Ground | 恢复地面控制并结束抓附消耗 |
| 任意玩法状态 | Esc | Paused | 冻结物理/玩法输入，保留状态快照 |

**抓附成功【已定】：** `HasValidSurface && SurfaceGap <= GrabStartGap && LMBHeld && StaminaUnlocked && CollisionClear`。LMB 仅代表请求。`GrabStartGap = 0.25 m`【建议初值，胶囊表面至岩壁可抓面】；已抓附的墙距保持与起抓距离分离（旧基线 `WallOffset ≈ 0.64 m`）。禁止把二者统一缩小，导致转角、上翻脱锁。

**体力归零：** 立刻强制松手，不再消耗攀爬体力；恢复到阈值且至少发生一次 LMB 释放后，才能再次尝试抓附。**下落重抓：** 在仍贴墙且再次满足所有条件时，按 LMB 可重新抓附，不能无视原有向下速度和碰撞。

### 4.2 墙面横移与内外转角（重点）

**几何抽象：** `ClimbSurface` 表示可攀爬碰撞表面，而非某个预设“内角/外角”；两块 90° L 形墙从一侧观察是凹角，另一侧就是凸角。允许正/反面的合法抓附组合。

**触发：** 玩家在 Climb 状态按住指向墙边的 A/D，距离边缘低于触发门槛。**查询：** 从当前墙面边界附近搜索可抓相邻墙面（含正/反面），计算法线、法线朝向和可用空间。**判断：** 基于接触面的几何和角色所在侧推导凹/凸，不能根据场景对象名称或手填枚举决定。

**运动路径：** 凹角采用可保证胶囊半径安全余量的分段路线；凸角采用绕边缘竖直轴的弧线；在移动前与移动中检查 CapsuleCast/Overlap，不能穿墙或关闭 Collider。路径由刚体受力跟踪；转角切入/切出速度连续，停输入可暂停推进但**仍保持抓附并扣体力**，松 LMB 立即坠落。

**覆盖矩阵：** A 正面 → B、B 正面 → A、A 背面 → B、B 背面 → A；对 Inner/Outer 两种几何关系均验证，共八个方向与接触面测试组合。不得只做到“内角专用场景”或“外角专用场景”。

**适用边界：** 本阶段规则竖直 BoxCollider 墙段；任意曲面、多个重叠 Mesh、可动墙壁及非 90° 复杂交汇需要下一专项，不在本版承诺范围内。

### 4.3 上翻 Mantle

触发前置：Climb、接近可达墙顶、Space 按下、顶面满足可站立坡度、足够胶囊空间且扫掠路径无遮挡。

**处理流程：** 墙顶检测 → 平台向下检测 → 胶囊空间校验 → 抬升 → 越边 → 落地站稳 → Ground。失败则维持 Climb 或安全进入 Air；不得瞬移上台。头顶不可抓悬石不能当作有效平台/攀爬面，若遮挡轨迹则上翻失败。

**待评审：** 上翻中途松 LMB 是立刻取消还是允许完成最后落地动作。为了遵守“松手即掉落”的现有手感基线，暂定 **松 LMB 立即终止上翻物理牵引并转 Air**，须经 Playtest 确认。

## 5. 体力和数值配置

### 5.1 体力规则

| 状态 | 消耗/恢复 | 规则 |
|---|---:|---|
| Climb/Corner/Mantle（成功抓附） | -20/s | 不论是否按 WASD，保持 LMB 即持续消耗 |
| Shift 快爬 | -30/s | 仅成功抓附状态生效 |
| Ground + Shift 跑步 | -25/s | 体力=0 禁用跑步 |
| Ground 普通步行/静止 | +18/s | 稳定恢复 |
| Airborne | 0/s | 既不恢复也不消耗攀爬体力 |
| LMB 按住但未抓到墙 | 不按抓附计费 | 地面按原地面规则；不能产生抓附音效 |

**基线参数：** `maxStamina=100`，疲劳后恢复至 `regrabUnlockStamina≈25` 才重开抓附（若实机配置不同，记录差异并经评审决定）。UI 缓动与显示残影绝不能改真实值。

### 5.2 建议配置表（核心字段）

| 参数键（逻辑字段名） | 类型/单位 | 初值 | 配置说明/验证 |
|---|---|---:|---|
| walkableSlopeMax | float / ° | 48 | 25°走、65°爬；临界角测试 |
| grabStartSurfaceGap | float / m | 0.25 | 胶囊表面到有效墙面；不得中心测距冒充 |
| climbHoldWallOffset | float / m | 0.64 | 成功抓附后的墙面约束距离；与起抓距离独立 |
| maxStamina | float / point | 100 | 真值由角色状态系统拥有 |
| climbStaminaDrain | float / point/s | 20 | 悬挂静止亦扣 |
| fastClimbStaminaDrain | float / point/s | 30 | 快爬扣 |
| sprintStaminaDrain | float / point/s | 25 | 跑步扣 |
| groundStaminaRegen | float / point/s | 18 | 普通步行/静止恢复 |
| exhaustedUnlockThreshold | float / point | 25 | 恢复且松过 LMB 才解锁 |
| moveSpeed | float / m/s | 4.0 | 保留现有配置值，可 Playtest 微调 |
| sprintSpeed | float / m/s | 9.5 | 遵循加速度而非瞬时切速 |
| climbSpeed | float / m/s | 2.2 | 平滑起停，松 LMB 不延迟 |
| fastClimbMultiplier | float / × | 1.9 | 比普通攀爬快 |
| cameraYawLimit | float / ° | 80/侧 | 相对角色逻辑朝向 |
| cameraPitchUp/Down | float / ° | 80/侧 | 初始水平，不俯视 |
| aimPromptFade | float / s | 0.10 | 动态准星过渡 |
| hintFade | float / s | 0.22 | 按键提示淡入淡出 |
| mediumDropHeight/highDropHeight | float / m | 8 / 18 | 区分落地反馈，不更改物理落地弹跳 |

**配置原则：** 这是策划目标初值，不是从本地 Scene 确认的实测真值。参数应聚合为可调配置并建立更改记录，最终以策划签字的配置表为准；不得由补丁直接覆写用户手工调整值。

## 6. 摄像机与角色表现规格

### 6.1 摄像机

- **类型：** 第三人称越肩可见角色；开场镜头在人物**正后方、接近眼部高度、水平看向人物朝向**，不能从顶上向下看。
- **输入：** 鼠标实时控制 Yaw/Pitch；基于独立人物逻辑朝向 Yaw 左右各 ±80°，Pitch 上下各 ±80°；锁标不消耗首次 LMB 抓附输入。
- **抗抖：** 小幅鼠标噪声死区+低通+旋转平滑；需兼顾微调精度，不能有明显输入迟滞。
- **遮挡：** SphereCast 让相机在墙体遮挡时适当缩近，遮挡解除时平滑恢复；不能因为墙壁碰撞/后退导致镜头闪动。
- **落地：** 高速下落可有很轻微反馈，实际着地时短促可关闭的震动；镜头偏移最终回归零，禁止每帧累积旋转。

### 6.2 视觉胶囊（不改碰撞）

跑步前倾、侧移侧倾、加减速惯性、攀爬轻度体态、落地压缩—回弹由 `ClimberPresentationPivot` 独立承担。表现必须基于固定起始 Transform 姿态计算上限，不能对 `CharacterVisualRoot` 叠加上一帧旋转；同一时间仅一个脚本拥有该 Transform 写入权。

## 7. UI/UX 交互与菜单

### 7.1 准星和按键提示

| 当前真实状态 | 中央图标 | 提示与优先级 |
|---|---|---|
| 普通自由移动 | `+` | 常态低存在感 |
| 当前可抓附且体力满足 | 绿色 `○` | 提示 `Hold LMB to Climb` |
| LMB 尝试抓附失败 | 红色 `×` | 提示抓附失败（短时出现，不持续刷屏） |
| Climb/Corner/Mantle | 蓝色 `↑` | 即便悬挂不移动也保持 |
| 地面接近可拾物 | 按键提示 `E Pick up` | 比普通移动说明更高优先级 |
| 体力耗尽 | 疲劳提示 | 高于普通抓附提示，减少误判 |
| Menu/Paused | 隐藏玩法准星、体力与按键提示 | UI 层级最高 |

**显示要求：** 动态准星过渡约 0.1s；HUD 不应因墙面检测在边缘一帧命中一帧失去而高频闪烁。体力条立即更新真值、填充动画平滑、旧值残影滞后跟随；视觉动画与实际扣血/耗体力数值必须解耦。

### 7.2 菜单交互流程

`MainMenu(Start / Exit) → Playing ←→ Paused(Resume / Exit)`。

- Play 时菜单覆盖当前场景，暂停世界模拟；Start 不重新加载场景，解除输入屏蔽并捕获鼠标。
- Playing 中 Esc 打开 Paused：`Time.timeScale=0`（及必要的独立输入/音频暂停），鼠标释放，角色、体力、物品与物理场景保持当前状态。
- Resume 或 Paused 下 Esc：从暂停点继续，恢复光标状态，不复制对象、不把暂停期间按键误判为抓附/拾取。
- Exit：Windows 构建调用程序退出；Unity Editor 中仅停止 Play Mode，不关闭 Unity 编辑器。
- 正式演示要求按钮有悬停/按下反馈且可点击；当前 OnGUI 可作为 prototype 方案，但必须能稳定点选与返回。

## 8. 音效与落地反馈需求单

| 事件 ID | 事件来源 | 声音 | 视觉/相机 | 验收重点 |
|---|---|---|---|---|
| EVT_GRAB_OK | 状态真正进入 Climb 时 | GrabSoft | 视觉轻收紧 | 未抓到不能响；事件同帧请求播放 |
| EVT_RELEASE | LMB 真实松手导致解除抓附时 | ReleaseSoft | 视觉释放 | 不能等到落地后才响 |
| EVT_LAND | 真实地面接触+下降速度满足阈值 | LandSoft | 短压缩回弹+落地镜头短震 | 普通侧面撞墙不触发；视觉与声音可感知同步 |

**音频资源：** `Assets/Audio/GrabSoft.wav`、`ReleaseSoft.wav`、`LandSoft.wav`；脚本从 Inspector 绑定 AudioClip，不应依赖不存在的 `Assets/PhysicsPrototype/Audio/`。短音效预加载、PCM/合适的 DSP 缓冲作为调优项。AudioSource 的 `AudioClip=None` 在使用 `PlayOneShot` 时允许，但事件脚本引用必须非空。

**异常测试：** 低落差、8m、18m；侧撞墙；连续跳跃；落地同时松开 LMB；打开暂停时音效；蓝牙耳机等设备输出缓冲差异。应分别记录“程序发出播放请求帧”“动画开始帧”“实际出声帧”或高帧录屏观察，不能用静态代码声称零延迟。

## 9. 拾取与既有道具

### 9.1 E 拾起 / 放下

合格对象必须有 `PhysicsCarryableItem`（或等效明确标记）且在有效距离与视线内。按 E 拾起后，道具位于玩家**右侧身边、摄像机可见且不被胶囊遮住**的位置；以镜头右向计算可视偏移并维持安全距离。持有时可暂时 Kinematic、关闭与玩家自身碰撞；E 放下后恢复原有重力与碰撞状态。暂停/Resume 不丢弃，也不重复生成物品。

### 9.2 已有两件道具（不新增）

| 名称 | 功能 | 物理实现方向 | 本阶段要求 |
|---|---|---|---|
| Spring Pad 弹力壁垫 | 贴墙放置、触碰弹出 | 墙面法线定位+碰撞冲量 | 保留既有次数/冷却/持续时间与 Q 使用逻辑 |
| Updraft Canister 上升气流罐 | 投掷后生成上升力场 | 投掷刚体+范围内持续加速度 | 保留现有半径/时长/受力对象与 T 使用逻辑 |

## 10. Mini Peak 关卡需求与资源规范

### 10.1 路线设计（Blockout）

`起点平地 → 25° 缓坡 → 小平台 → 65° 陡坡 → 上层平台 → L形墙双侧转角 → 墙顶上翻 → 山顶`。

额外包含一块**带物理碰撞但无 ClimbSurface** 的头顶悬石，验证无法抓附且会阻挡不合理上翻；在起点/平台/山顶放置可拾物。原独立测试区继续保留直墙、正反面内外角、动态箱子、8m 中落差和 18m 高落差。

### 10.2 场景规范

- 一切攀爬面应以 `ClimbSurface` 实际配置为真源；同一 L 形墙内外两侧都应可测试，不依赖旧 `ClimbCorner` 或 Inner/Outer Pivot。
- 基础 Blockout 色彩：可抓岩壁蓝灰、缓坡绿色、动态障碍橙色、普通地面灰色；颜色不影响 Collider 摩擦。
- 关卡创建工具需**增量且幂等**：已有同名区域时跳过或提示人工选择，绝不覆盖用户手动调整的墙壁位置和场景对象。
- 编辑器 Debug Teleport 用于快速测试各站点，不能变成正式玩法捷径。
